# Development log

A dated record of how pyNR was developed. Each entry covers what changed
and why, what was measured, and what was left open. Entries have four
sections:

- **Physics:** what the code can now simulate, and what the runs showed.
- **Numerical analysis:** discretisation, stability, convergence and accuracy findings.
- **Implementation:** architecture, performance, tooling and infrastructure.
- **Roadmap / TODO:** what comes next, and why, in priority order.
